# New Mobile Feature

Plan and implement a cross-platform mobile feature from architecture through testing.

## Arguments
- `$ARGUMENTS` — Feature description.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read AGENTS.md, `package.json`/`pubspec.yaml`, project structure
2. Identify framework, navigation, state management, existing patterns

## Phase 2: Architecture
Use the task tool to invoke `@mobile-architect` with feature description and project context.

## Phase 3: Implement
Use the task tool to invoke `@mobile-builder` with the architect's blueprint.

## Phase 4: Test
Use the task tool to invoke `@mobile-tester` with test instructions.

## Phase 5: Review
Use the task tool to invoke `@mobile-reviewer` with all new/modified files.

## Phase 6: Fix Cycle
Max 2 rounds.

## Phase 7: Report
Present: feature summary, files changed, platform notes, tests, review findings.
