# Run Mobile Tests

Run the mobile project's test suite.

## Arguments
- `$ARGUMENTS` — Optional test scope.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read AGENTS.md, identify test framework
2. Read test config, determine test command

## Phase 2: Run Tests
Use the task tool to invoke `@mobile-tester` with the test command and scope.

## Phase 3: Report
Present: pass/fail counts, failures, platform coverage.
