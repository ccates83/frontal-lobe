# Infrastructure Audit

Comprehensive audit of infrastructure for security, reliability, cost, and best practices.

## Arguments
- `$ARGUMENTS` — Optional focus area. Defaults to full audit.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read project guidance (CLAUDE.md or project guidance (CLAUDE.md or AGENTS.md)), scan for all infrastructure files
2. Map the infrastructure: Docker, K8s, Terraform, Nginx, monitoring
3. Determine audit scope

## Phase 2: Audit
Delegate to the `devops-reviewer` subagent with comprehensive audit instructions covering security, reliability, cost, and best practices.

## Phase 3: Report
Present: critical findings, security posture, cost optimization opportunities, priority action items.
