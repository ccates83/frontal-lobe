# Build Mobile Project

Build the mobile project and report results.

## Arguments
- `$ARGUMENTS` — Optional build target or platform.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read project guidance (CLAUDE.md or project guidance (CLAUDE.md or AGENTS.md)), identify framework (React Native, Expo, Flutter)
2. Read `package.json` / `pubspec.yaml` for build scripts
3. Determine build command

## Phase 2: Build
Delegate to the `mobile-builder` subagent with build instructions. Fix errors (max 2 rounds).

## Phase 3: Report
Present: build status, platform notes, errors/warnings.
