# Data Review

Review database code for correctness, performance, and security.

## Arguments
- `$ARGUMENTS` — What to review.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read project guidance (CLAUDE.md or project guidance (CLAUDE.md or AGENTS.md)), existing schema, ORM config
2. Determine review scope

## Phase 2: Review
Delegate to the `data-reviewer` subagent with files and context.

## Phase 3: Report
Present: findings by severity, performance recommendations, security concerns.
