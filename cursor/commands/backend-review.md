# Backend Code Review

Review backend code for bugs, concurrency issues, security, and convention violations.

## Arguments
- `$ARGUMENTS` — What to review.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read project guidance (CLAUDE.md or project guidance (CLAUDE.md or AGENTS.md)), identify language and framework
2. Determine review scope

## Phase 2: Review
Delegate to the `backend-reviewer` subagent with files and project context.

## Phase 3: Report
Present: findings by severity, concurrency notes, security concerns.
