# API Review

Review API design for consistency, security, performance, and best practices.

## Arguments
- `$ARGUMENTS` — What to review.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read project guidance (CLAUDE.md or project guidance (CLAUDE.md or AGENTS.md)), existing API structure, specs
2. Identify protocol, framework, auth method
3. Determine review scope

## Phase 2: Review
Delegate to the `api-reviewer` subagent with endpoints and context.

## Phase 3: Report
Present: consistency issues, security findings, breaking changes, recommendations.
