# Run Mobile Tests

Run the mobile project's test suite.

## Arguments
- `$ARGUMENTS` — Optional test scope.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read project guidance (CLAUDE.md or project guidance (CLAUDE.md or AGENTS.md)), identify test framework
2. Read test config, determine test command

## Phase 2: Run Tests
Delegate to the `mobile-tester` subagent with the test command and scope.

## Phase 3: Report
Present: pass/fail counts, failures, platform coverage.
