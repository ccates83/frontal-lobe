# Run Backend Tests

Run the backend project's test suite.

## Arguments
- `$ARGUMENTS` — Optional test scope or filter.

## Instructions
You are an orchestrator. Plan and delegate.

## Phase 1: Understand Context
1. Read project guidance (CLAUDE.md or project guidance (CLAUDE.md or AGENTS.md)), identify language and test framework
2. Determine test command

## Phase 2: Run Tests
Delegate to the `backend-tester` subagent with the test command and scope.

## Phase 3: Report
Present: pass/fail counts, failures with details, coverage if available.
